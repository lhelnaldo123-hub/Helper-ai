# Tender Sprout AI

An AI teaching and learning helper for teachers and students.

**Live demo:** https://lhelnaldo123-hub.github.io/Helper-ai/

## Features
- AI chat with a choice of Gemini models
- Quiz Maker: objective, theory or mixed, BECE-style, with timer and results
- GES / NaCCA lesson plan generator (copy, print or download)
- PowerPoint slide generator with .pptx download
- Assignment Scanner: take a photo and get step-by-step help
- Twi and French support
- Code Preview for live website previews
- Chat history, dark and light mode
- Installable on a phone (PWA)

## Built with
- HTML, CSS and JavaScript
- Google Gemini API
- GitHub Pages hosting

## Note
You add your own free Gemini API key in Settings. It is saved on your device only. AI can make mistakes, so check important information.
