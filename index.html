🎛️ App settings

📲 Install as an app

Android (Chrome): tap the ⋮ menu, then Install app or Add to Home screen.

iPhone / iPad (Safari): tap the Share button (square with arrow), scroll down, then tap Add to Home Screen.

This works only when the app is opened from its web link (https). It cannot be installed from a file stored on the phone.

⚙️ Settings

Paste your Gemini API key once. It is saved on this phone, not in the code, so you will not be asked again.

Chat uses the model at the top. Advanced models need a paid Google AI Studio key (billing turned on). If a model does not work, the app uses Gemini 3.8 Flash and tells you.

GitHub upload (optional). Lets you send files from the app straight to your repo. On GitHub: Settings → Developer settings → Fine-grained tokens → create a token for your repo with Contents: Read and write. It is saved on this phone only.

Get a free API key at aistudio.google.com → Create API key. If a model fails, the app automatically tries Gemini 3.8 and 3.5.

🧠 Memory & Learning

The app saves what you teach it, the lessons and quizzes you generate, and your ratings. It uses the most relevant notes to improve new answers. Everything stays on this device only, and you control it here.

👑 Owner (shared learning)

📁 My Projects

CVs, documents, memos and code pages you saved from chat. They are kept on this phone, so use Export to keep a backup.

👑 Review suggestions

Short notes sent anonymously by phones using the app. Approve the good ones and they reach everyone. Chats are never sent.

📝 AI instructions

These are the instructions the AI follows. It can propose an improved version from your feedback, but nothing changes until you approve it, and you can go back to any older version. Safety lines are locked and always added.
