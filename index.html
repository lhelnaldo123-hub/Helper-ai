📲 Install as an app

Android (Chrome): tap the ⋮ menu, then Install app or Add to Home screen.

iPhone / iPad (Safari): tap the Share button (square with arrow), scroll down, then tap Add to Home Screen.

This works only when the app is opened from its web link (https). It cannot be installed from a file stored on the phone.

⚙️ Settings

Paste your Gemini API key once. It is saved on this phone, not in the code, so you will not be asked again.

Get a free API key at aistudio.google.com → Create API key. If a model fails, the app automatically tries Gemini 3.8 and 3.6.
